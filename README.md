# 電話（PhoneClone）スターター v1.3

iPhoneの純正電話アプリを再現した、着信履歴を自分で作れるアプリです。
実際の通話はできません。履歴の作成・編集と、通話画面の再現を楽しむためのアプリです。

- Bundle ID：com.example.phoneclone
- 表示名：電話
- 対応：iOS 17以上（LiveContainerでの利用を想定）

## 機能

### 履歴（メイン機能）
- 純正風の履歴一覧（すべて／不在着信の切り替え付き）
- 連続した同じ相手の履歴は、純正と同じように（2）のようにまとめて表示されます
- 右上の「＋」から履歴を自由に追加できます
  - 名前・電話番号・ラベル（携帯電話／自宅／勤務先／その他）
  - 種類（着信／発信／不在着信）
  - 日時、通話時間（分・秒）
- 不在着信は赤字、発信には発信マークが付きます
- 左上の「編集」またはスワイプで削除できます
- 行をタップすると疑似通話が始まります。「i」ボタンで相手ごとの詳細画面へ

### 詳細画面（「i」ボタン）
- 相手の全履歴（日時・種類・通話時間）の一覧
- 履歴をタップすると1件ずつ編集できます
- お気に入りへの追加／削除、この番号の履歴をすべて削除

### キーパッド
- 純正風キーパッド（英字付き、0長押しで＋）
- 入力した番号が履歴や連絡先にあれば名前を表示します
- 緑のボタンで疑似通話、「履歴に追加」からそのまま履歴も作れます

### 疑似通話画面
- 発信すると通話画面が開き、2秒後に通話時間のカウントが始まります
- 終了ボタンで切ると、実際の通話時間で発信履歴に自動で記録されます
- 消音・スピーカーのボタンは見た目だけ切り替わります

### お気に入り／連絡先／留守番電話
- お気に入り：追加・編集・削除。タップで疑似通話
- 連絡先：履歴とお気に入りから自動で一覧化（検索付き）
- 留守番電話：追加・削除ができ、再生画面の再現（プログレスバー）付き。未読はタブにバッジ表示

### データ
- すべて端末内（DocumentsのJSON）に保存され、再起動しても残ります
- 初回起動時はサンプルの履歴・お気に入り・留守電が入っています（すべて削除・編集できます）

## ビルド方法

1. このフォルダの中身をGitHubリポジトリにアップロード（GHUploader等）
2. Actionsタブで「Build IPA」が自動実行される
3. 完了したらArtifactsから `PhoneClone-ipa` をダウンロードし、IPAを取り出してLiveContainerにインポート

## 注意

- 実際の発信・着信・SMS送信は一切行いません
- メッセージ／ビデオ／メールボタンは再現用で、押すとその旨の案内が出ます
